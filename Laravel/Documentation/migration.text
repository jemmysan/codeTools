------ Créer une nouvelle colonne -------
1- php artisan make:migration add_new_column_to_table_name --table=table_name
2- modifier la methode up en y ajoutant l'attribut

---- SoftDeletes ---
1- Ajout dans le modeles SoftDeletes
2- Créer colonne delete_at si elle n'existe pas
    => add_deleted_at_to_table_name
3- Migrates en ajoutant  $table->softDeletes() dans la methode up()
    et  $table->dropColumn('deleted_at') a la methode down;
