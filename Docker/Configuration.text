*********** Installing Process ************

1- Download and install docker on local machine
2- Launch docker
3- Create Dockerfile   
4- Create docker-compose.yml
5- Run 
    a- docker-compose build
    b- docker-compose up
6- Check container
    - docker ps -a
7- Start container
    docker start <nom_du_conteneur>

    Si vous ne disposez pas d'un fichier docker-compose.yml et que vous exécutez les conteneurs individuellement, vous pouvez démarrer chaque conteneur individuellement à l'aide de la commande docker start.
    docker start annuairestartup-app-1
    docker start annuairestartup-db-1
